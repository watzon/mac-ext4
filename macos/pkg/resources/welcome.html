Ext4 for Mac

Read and write Linux ext2, ext3, and ext4 drives in Finder, and format drives as ext4.

This installer adds

  • Ext4.app in Applications, with the file system module that macOS uses to mount ext drives.
  • The format name Finder shows ("Linux ext4"), in /Library/Filesystems/ext4.fs.
  • The ext4 command-line tool in /usr/local/bin, for formatting, checking, mounting, and unmounting.
Ext drives that are mounted now are unmounted before the installer replaces the module. Close any files on them first.

Requires macOS 15.4 or later. No kernel extension and no change to security settings.
