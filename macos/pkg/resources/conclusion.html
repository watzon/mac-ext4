One more step: turn on Ext4

macOS does not use a new file system module until you turn it on. Ext4.app opens now and shows a button that takes you to the right place in System Settings. Or do it yourself:

  1. Open System Settings > General > Login Items & Extensions.
  2. Under Extensions, switch the list to By Category.
  3. Click ⓘ next to File System Extensions and turn on Ext4.
The switch in the "By App" list does not respond on current macOS versions. Use the category list.

After that

  • Connect an ext2, ext3, or ext4 drive. It opens in Finder like any other drive.
  • To format a partition as ext4 (this erases it): sudo newfs_fskit -t ext4 -L NAME diskNsM. Find the partition with diskutil list.
  • Eject from Finder, or run ext4 unmount /Volumes/NAME.
